PRISM Live setup

  1. Host this HTML page on a static HTTPS host such as GitHub Pages.
  2. Open the hosted page on your phone and use the controller.
  3. In PRISM, add a Web Browser / Web source and enter the same page URL with ?overlay=1 at the end.
  4. Set the source to fit your 16:9 landscape stream and place it along the bottom.

Important: This starter version syncs tabs in the same browser using local storage. PRISM's separate in-app browser may not share that storage. For reliable phone-to-PRISM syncing, a free cloud database connection (Firebase or Supabase) and hosting setup are needed; this file does not pretend to provide cross-app cloud sync out of the box.
